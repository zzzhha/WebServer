## 1. TcpServer（TCP服务器编排）

### 文件信息
- **头文件**: [tcpserver.h](file:///home/zsy/WebServer/cppBackend/reactor/tcpserver.h)
- **实现文件**: [tcpserver.cpp](file:///home/zsy/WebServer/cppBackend/reactor/tcpserver.cpp)

### 核心功能
TcpServer 负责组织 Reactor 模式的整体架构，管理主从 EventLoop、IO 线程池和所有连接的生命周期。

### 主要成员变量
```cpp
private:
  std::unique_ptr<EventLoop> mainloop_;          // 主事件循环（负责 accept）
  std::vector<std::unique_ptr<EventLoop>> subloops_; // 从事件循环容器（负责 I/O）
  Acceptor acceptor_;                           // Acceptor 对象（管理 listenfd）
  int threadnum_;                               // IO 线程数量
  ThreadPool threadpool_;                       // IO 线程池
  std::mutex mmutex_;                           // 保护 conns_ 的互斥锁
  std::map<int, spConnection> conns_;           // 活跃连接映射表
  std::function<void(spConnection)> newconnectioncb_;     // 新连接回调
  std::function<void(spConnection)> closeconnectioncb_;   // 连接关闭回调
  std::function<void(spConnection)> errorconnectioncb_;   // 连接错误回调
  std::function<void(spConnection)> onmessagecb_;         // 消息到达回调
  std::function<void(spConnection)> sendcompletecb_;      // 发送完成回调
  TimeWheel time_wheel_;                         // 时间轮（连接超时管理）
```

### 关键方法

#### newconnection() - 处理新连接
```cpp
void TcpServer::newconnection(std::unique_ptr<Socket> clientsock) {
  // 选择从事件循环（fd % threadnum_）
  int idx = clientsock->fd() % threadnum_;
  
  // 创建 Connection 对象
  spConnection conn = std::make_shared<Connection>(
    subloops_[idx].get(), std::move(clientsock)
  );
  
  // 设置回调函数
  conn->setclosecallback(std::bind(&TcpServer::closeconnection, this, std::placeholders::_1));
  conn->seterrorcallback(std::bind(&TcpServer::errorconnection, this, std::placeholders::_1));
  conn->setonmessage(std::bind(&TcpServer::message, this, std::placeholders::_1));
  conn->setsendcomplete(std::bind(&TcpServer::sendcomplete, this, std::placeholders::_1));
  
  // 添加到连接映射表
  {
    std::lock_guard<std::mutex> lock(mmutex_);
    conns_[conn->fd()] = conn;
  }
  
  // 在所属 IO 线程中完成连接建立
  subloops_[idx]->queueinloop(std::bind(&Connection::connectEstablished, conn));
  
  // 添加到时间轮
  add_new_conn_timernode(conn);
  
  // 回调上层新连接处理
  if (newconnectioncb_) newconnectioncb_(conn);
}
```

**功能**: 接受新连接，创建 Connection 对象，设置回调，注册到时间轮
**调用位置**: `Acceptor::newconnection` 回调

### 设计特点
- **主从 Reactor 模式**: 一个主 EventLoop 负责 accept，多个从 EventLoop 负责 I/O
- **连接均衡**: 使用 `fd % threadnum_` 策略分配连接到不同的从 EventLoop
- **线程安全**: 使用互斥锁保护连接映射表
- **超时管理**: 集成 TimeWheel 进行连接超时检测

### 核心功能
Connection 管理单个 TCP 连接的完整生命周期，包括数据读写、事件处理、TLS支持和文件传输。

### 主要成员变量
```cpp
private:
  EventLoop* loop_;                    // 所属的 EventLoop
  std::unique_ptr<Socket> clientsock_; // 客户端 socket
  std::unique_ptr<Channel> clientchannel_; // 客户端 channel
  BufferBlock inputbuffer_;            // 输入缓冲区
  BufferBlock outputbuffer_;           // 输出缓冲区
  std::function<void(spConnection)> closecallback_;   // 关闭回调
  std::function<void(spConnection)> errorcallback_;   // 错误回调
  std::function<void(spConnection)> onmessage_;       // 消息回调
  std::function<void(spConnection)> sendcomplete_;    // 发送完成回调
  bool close_on_send_complete_{false}; // 发送完成后是否关闭连接
  std::any context_;                   // 连接上下文（存储 HttpFacade 等）
  std::shared_ptr<TlsSession> tls_session_; // TLS 会话
  SendFileCtx sendfile_ctx_;           // 文件发送上下文
```

### 关键方法

#### onmessage() - 处理接收到的数据
```cpp
void Connection::onmessage() {
  char buffer[4096];
  while (true) {
    ssize_t nread;
    
    if (tls_session_) {
      // TLS 连接：使用 SSL_read
      nread = tls_session_->Read(buffer, sizeof(buffer));
    } else {
      // 明文连接：使用 recv
      nread = recv(fd(), buffer, sizeof(buffer), 0);
    }
    
    if (nread > 0) {
      // 有效数据：添加到输入缓冲区
      inputbuffer_.append(buffer, nread);
    } else if (nread == 0) {
      // 对端关闭连接
      if (closecallback_) closecallback_(shared_from_this());
      return;
    } else {
      // 错误处理
      if (errno == EAGAIN || errno == EWOULDBLOCK) {
        // 数据读取完成，回调上层处理
        if (onmessage_) onmessage_(shared_from_this());
        return;
      } else if (errno == EINTR) {
        // 被信号中断，继续读取
        continue;
      } else {
        // 其他错误，触发错误回调
        if (errorcallback_) errorcallback_(shared_from_this());
        return;
      }
    }
  }
}
```

**功能**: 循环读取 socket 数据，处理 TLS/明文两种模式，支持边缘触发
**调用位置**: `Channel::handleevent` 中的读事件回调

#### send() - 发送数据
```cpp
void Connection::send(const char* data, size_t size) {
  if (loop_->isinloopthread()) {
    // 在 IO 线程中：直接执行
    sendinloop(data, size);
  } else {
    // 不在 IO 线程中：投递任务到 IO 线程
    loop_->queueinloop(std::bind(&Connection::sendinloop, shared_from_this(), data, size));
  }
}
```

**功能**: 线程安全的发送数据，支持跨线程投递
**调用位置**: `HttpServer` 发送 HTTP 响应时调用

#### writecallback() - 写事件回调
```cpp
void Connection::writecallback() {
  if (outputbuffer_.avail() > 0) {
    // 有数据需要发送
    ssize_t nwritten;
    
    if (tls_session_ && tls_session_->IsKTlsTxEnabled()) {
      // kTLS 已启用：使用 writev
      auto iovecs = outputbuffer_.getIOVecs();
      nwritten = writev(fd(), iovecs.data(), iovecs.size());
    } else if (tls_session_) {
      // TLS 连接（非 kTLS）：使用 SSL_write
      nwritten = tls_session_->Write(outputbuffer_.data(), outputbuffer_.avail());
    } else {
      // 明文连接：使用 writev
      auto iovecs = outputbuffer_.getIOVecs();
      nwritten = writev(fd(), iovecs.data(), iovecs.size());
    }
    
    // 更新缓冲区
    if (nwritten > 0) {
      outputbuffer_.consume(nwritten);
    }
  }
  
  // 检查是否发送完成
  if (outputbuffer_.avail() == 0) {
    // 禁用写事件监控
    clientchannel_->disablewriting();
    
    // 回调发送完成
    if (sendcomplete_) sendcomplete_(shared_from_this());
    
    // 如果需要，关闭连接
    if (close_on_send_complete_) {
      if (closecallback_) closecallback_(shared_from_this());
    }
  }
}
```

**功能**: 处理写事件，发送输出缓冲区中的数据，支持多种发送模式
**调用位置**: `Channel::handleevent` 中的写事件回调

### 设计特点
- **双缓冲区**: `inputbuffer_` 和 `outputbuffer_` 分别管理读写数据
- **TLS集成**: 支持 TLS 1.2 和 kTLS 硬件加速
- **文件传输**: 支持 `sendfile` 零拷贝文件传输
- **线程安全**: 支持跨线程操作，通过任务队列投递

Acceptor 封装监听 socket，负责接受新的 TCP 连接并将其传递给 TcpServer。

### 关键方法

#### newconnection() - 接受新连接
```cpp
void Acceptor::newconnection() {
  while (true) {
    std::unique_ptr<Socket> clientsock = serversock_.accept();
    if (!clientsock) {
      // accept 返回 EAGAIN/EWOULDBLOCK，本轮 accept 结束
      if (errno == EAGAIN || errno == EWOULDBLOCK) {
        return;
      }
      // 其他错误，记录日志
      LOGERROR("accept error: " + std::string(strerror(errno)));
      return;
    }
    
    // 设置 TCP_NODELAY 选项
    clientsock->setTcpNoDelay(true);
    
    // 回调 TcpServer 处理新连接
    newconnectioncb_(std::move(clientsock));
  }
}
```

**功能**: 循环 accept 新连接，支持边缘触发模式
**调用位置**: `Channel::handleevent` 中的监听 socket 读事件回调

### 设计特点
- **边缘触发**: 使用 while 循环接受所有就绪的连接
- **错误处理**: 正确处理 EAGAIN/EWOULDBLOCK 和其他错误
- **选项设置**: 为新连接设置 TCP_NODELAY 选项

## 4. Buffer（缓冲区）

### 文件信息
- **头文件**: [Buffer.h](file:///home/zsy/WebServer/cppBackend/reactor/Buffer.h)
- **实现文件**: [Buffer.cpp](file:///home/zsy/WebServer/cppBackend/reactor/Buffer.cpp)

### 核心功能
BufferBlock 提供高效的数据缓冲区管理，支持分块存储、零拷贝读取和批量发送。

### 主要特性
- **分块存储**: 使用多个内存块存储数据，避免大块内存分配
- **内存池分配**: 使用 MemoryPool 分配内存块，提高性能
- **零拷贝读取**: `getIOVecs()` 返回 iovec 数组，支持 `writev` 批量发送
- **自动扩容**: 根据需要自动分配新的内存块

### 关键方法

#### append() - 追加数据
```cpp
void BufferBlock::append(const char* data, size_t len) {
  // 确保有足够空间
  ensureSpace(len);
  
  // 复制数据到当前块
  size_t to_copy = std::min(len, current_block_->size - write_offset_);
  memcpy(current_block_->data + write_offset_, data, to_copy);
  write_offset_ += to_copy;
  len -= to_copy;
  
  // 如果需要，继续复制到新块
  if (len > 0) {
    allocNewBlock();
    append(data + to_copy, len);
  }
}
```

#### getIOVecs() - 获取 iovec 数组
```cpp
std::vector<struct iovec> BufferBlock::getIOVecs() const {
  std::vector<struct iovec> iovecs;
  
  // 遍历所有块，构建 iovec 数组
  for (auto it = blocks_.begin(); it != blocks_.end(); ++it) {
    Block* block = *it;
    size_t data_start = (it == blocks_.begin()) ? read_offset_ : 0;
    size_t data_len = (it == last_block_) ? (write_offset_ - data_start) : 
                      (block->size - data_start);
    
    if (data_len > 0) {
      iovec vec;
      vec.iov_base = block->data + data_start;
      vec.iov_len = data_len;
      iovecs.push_back(vec);
    }
  }
  
  return iovecs;
}
```

**功能**: 构建用于 `writev` 系统调用的 iovec 数组，实现零拷贝发送

### 核心功能
ThreadPool 提供通用的线程池实现，用于管理 IO 线程和工作线程。

### 关键方法

#### addtask() - 添加任务
```cpp
void ThreadPool::addtask(std::function<void()> fn) {
  {
    std::unique_lock<std::mutex> lock(mutex_);
    tasks_.push(fn);
    queue_size_++;
  }
  cond_.notify_one();
}
```

#### worker() - 工作线程函数
```cpp
void ThreadPool::worker() {
  while (true) {
    std::function<void()> task;
    
    {
      std::unique_lock<std::mutex> lock(mutex_);
      cond_.wait(lock, [this]() { return stop_ || !tasks_.empty(); });
      
      if (stop_ && tasks_.empty()) return;
      
      task = std::move(tasks_.front());
      tasks_.pop();
      queue_size_--;
    }
    
    task();
  }
}
```

### 设计特点
- **任务队列**: 使用队列管理待执行任务
- **条件变量**: 使用条件变量实现线程等待/唤醒
- **优雅停止**: 支持安全地停止所有线程
- **队列统计**: 提供队列大小统计，用于背压控制
