# Reactor 模块总体介绍

## 目录结构概述

`/home/zsy/WebServer/cppBackend/reactor` 目录包含了基于 epoll 的 Reactor 网络框架实现，并为上层 HTTP 服务器提供运行时环境。该模块是 C++ HTTP 服务器的核心网络层，负责处理所有网络 I/O 事件、连接管理和数据传输。

## 文件分类与用途

### 1. Reactor 核心三件套
- **EventLoop** (`Eventloop.h/cpp`): 事件循环核心，驱动 epoll_wait 并分发事件
- **Epoll** (`Epoll.h/cpp`): epoll 系统调用封装，管理文件描述符的注册和监控
- **Channel** (`Channel.h/cpp`): 文件描述符与事件的绑定，包含读写回调函数

### 2. TCP 服务器编排
- **TcpServer** (`tcpserver.h/cpp`): 服务器主类，管理主从 EventLoop、IO 线程池和连接生命周期
- **Acceptor** (`Acceptor.h/cpp`): 监听套接字管理器，接受新连接
- **Connection** (`Connection.h/cpp`): 连接管理器，处理单个连接的读写操作

### 3. 网络基础组件
- **Socket** (`Socket.h/cpp`): 套接字封装类
- **InetAddress** (`InetAddress.h/cpp`): IP 地址和端口封装
- **Buffer** (`Buffer.h/cpp`): 读写缓冲区，支持 writev 批量发送

### 4. HTTP 服务器适配层
- **HttpServer** (`HttpServer.h/cpp`): HTTP 业务适配层，将网络事件转换为 HTTP 处理
- **main.cpp**: 程序入口点，初始化 HttpServer 并启动服务

### 5. TLS/SSL 支持
- **TlsContext** (`TlsContext.h/cpp`): TLS 上下文配置（证书、私钥等）
- **TlsSession** (`TlsSession.h/cpp`): TLS 会话管理，支持 kTLS 硬件加速

### 6. 工具类
- **ThreadPool** (`ThreadPool.h/cpp`): 线程池实现，用于 IO 线程和工作线程
- **Timestamp** (`Timestamp.h/cpp`): 时间戳工具类
- **RouteMetricsUtil** (`RouteMetricsUtil.h/cpp`): 路由指标统计工具

### 7. 配置文件
- **CMakeLists.txt**: CMake 构建配置
- **makefile**: Makefile 构建配置
- **readme.md**: 模块流程概述文档
- **tmp.sh**: 临时脚本文件

## 核心架构设计

### 1. Reactor 模式
- **主从 Reactor**: 一个主 EventLoop 负责 accept 新连接，多个从 EventLoop 负责处理 I/O
- **IO 多路复用**: 使用 epoll 边缘触发模式
- **事件驱动**: 所有操作基于网络事件回调

### 2. 连接生命周期管理
- **新建连接**: `Acceptor::newconnection` → `TcpServer::newconnection` → `Connection::connectEstablished`
- **数据读取**: `Channel::handleevent` → `Connection::onmessage` → `HttpServer::HandleMessage`
- **数据发送**: `Connection::send` → `Connection::writecallback` → `writev` 批量发送
- **连接关闭**: 错误处理或正常关闭流程

### 3. 缓冲区设计
- **双缓冲区**: `inputbuffer_` 和 `outputbuffer_` 分别管理读写数据
- **内存池分配**: 使用 MemoryPool 分配缓冲区块，提高内存使用效率
- **零拷贝支持**: 支持 `writev` 系统调用进行批量数据发送

### 4. TLS 集成
- **连接级 TLS**: 每个连接独立管理 TLS 会话
- **kTLS 支持**: 优先使用内核 TLS 硬件加速
- **明文/密文分离**: 网络层处理加密/解密，HTTP 层只处理明文

## 关键特性

### 1. 高性能设计
- 边缘触发 epoll 模式
- 零拷贝缓冲区管理
- 内存池分配减少系统调用
- IO 线程池避免线程争用

### 2. 稳定性保障
- 跨线程安全的事件投递
- 完善的错误处理和连接关闭
- 背压控制防止内存溢出
- 超时连接自动清理

### 3. 可扩展性
- 模块化设计，组件可替换
- 支持 Phase2 异步处理链路
- 连接上下文支持自定义业务对象
- 易于集成其他协议

## 典型工作流程

### 启动阶段
1. `main.cpp` 创建 `HttpServer` 实例
2. `HttpServer` 初始化 `TcpServer` 和 `ThreadPool`
3. `TcpServer` 创建主从 `EventLoop` 并启动 IO 线程池
4. `EventLoop::run` 开始事件循环

### 连接建立
1. `Acceptor` 监听 socket 可读事件
2. `accept4` 接受新连接，创建 `Socket` 对象
3. `TcpServer::newconnection` 选择从 `EventLoop` 并创建 `Connection`
4. `Connection::connectEstablished` 在 IO 线程中注册 epoll 事件

### 数据处理
1. `Channel::handleevent` 分发读事件到 `Connection::onmessage`
2. `Connection` 读取数据到 `inputbuffer_`
3. `HttpServer::HandleMessage` 处理 HTTP 请求
4. 生成响应数据写入 `outputbuffer_`
5. `Connection::send` 触发写事件发送数据
