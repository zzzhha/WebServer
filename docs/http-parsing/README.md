# HTTP请求解析技术文档

## 文档概述
本文档围绕本仓库的 C++ HTTP 服务器实现，阐述从 TCP 连接到 HTTP 报文解析、校验、路由、静态文件/下载响应输出的完整链路。文档以“源码行为”为准：不引入仓库中不存在的伪接口/伪类，涉及实现细节均以源码链接为依据。

## 目录
1. 第1章：TCP连接建立与连接管理（参见 chapter1.md）
2. 第2章：HTTP解析入口、状态机与缓冲区（参见 chapter2.md）
3. 第3章：GET请求处理：路由与静态文件（参见 chapter3.md）
4. 第4章：POST请求体读取：Content-Length 与 chunked（参见 chapter4.md）
5. 第5章：chunked 解码：状态转换与边界条件（参见 chapter5.md）
6. 第6章：下载请求：Range/缓存头/sendfile（参见 chapter6.md）
7. 第7章：错误处理与超时控制（参见 chapter7.md）
8. 第8章：并发模型与内存管理要点（参见 chapter8.md）
9. 图表汇总（参见 diagrams.md）

## 核心特性
- 完整链路：TCP连接、缓冲区收包、HTTP解析、责任链校验、路由分发、响应输出
- 关键特性：chunked 解码、Range 断点续传、缓存头（ETag/Last-Modified）、sendfile 文件直传
- 健壮错误处理：解析错误/超大报文/不支持版本/路由失败映射到标准状态码
- 高性能基础：Reactor 并发模型、BufferBlock + MemoryPool、文件零拷贝输出
- 可视化支持：流程图、状态机图、时序图、架构图（Mermaid语法）

- 协议标准：HTTP/1.1（RFC 9112）、Range（RFC 9110/9112 语义）
- 状态码：以实现中的 HttpStatusCode 映射为准
- 工程约束：链接到真实源码；不粘贴仓库中不存在的伪实现
- 代码质量：模块化、异常安全（RAII）、线程安全、可测试性（依赖注入）

## 使用指南
- 快速开始：先读第1、2章；按需查看第3、4章实现具体请求处理
- 高级特性：第5章（chunked）、第6章（下载优化）、第7章（错误处理）、第8章（性能与并发）
- 图表参考：见 diagrams.md，可直接用于技术分享与设计评审

## 最佳实践
- 性能优化：sendfile 大文件传输、BufferBlock 复用、事件驱动解耦
- 可靠性保障：解析超时、请求路径安全校验、资源限制（Header/Body 上限）
- 可靠性保障：多层超时控制、令牌桶限流、错误隔离、资源限制
